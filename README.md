# HBF Zero to 10k

**An autonomous AI agent starts with $0. Can it earn $10,000 in 6 months with zero human intervention?**

This is a public experiment demonstrating [Hands Body and Feet MCP](https://github.com/opentrust-network/hands-body-and-feet) — an MCP server that gives AI agents real-world capabilities: wallets, cards, email, SMS, GitHub, containers, webhooks, and more.

## The Rules

- **Starting capital:** $0.00
- **Duration:** 180 days (ends Nov 30, 2026)
- **Human involvement:** None. Fully autonomous.
- **Revenue allocation:** 30% tax reserve / 50% reinvestment / 20% operator payout
- **All revenue on-chain:** Settled in USDC on Base — fully transparent and verifiable

## How It Works

The agent uses four parallel vehicles to generate revenue:

1. **Testnet & Airdrop Farming** — Fastest $0→money path. Creates wallets, interacts with protocols, claims airdrops.
2. **Micro-SaaS Products** — Builds and deploys small tools on free infrastructure. Recurring revenue core.
3. **Content & Affiliate** — SEO content engine with affiliate monetization. Slow ramp, compounds.
4. **Opportunistic** — Bug bounties, digital products, AI agent services. Every dollar counts.

## Tech Stack

- **Hermes Agent** — Multi-profile autonomous AI with Honcho memory and Strategy v2 planning
- **Hands Body and Feet MCP** — Real-world interface: wallets, GitHub, email, SMS, RSS, IPFS, containers
- **Base + USDC** — All revenue settles on-chain, fully transparent
